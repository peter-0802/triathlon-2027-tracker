# Triathlon 2027 Tracker

A local-first Progressive Web App for Android and desktop.

## Run locally
Open `index.html` in a modern browser. Workout records are saved in that browser's local storage. Some PWA/offline features require HTTPS or localhost.

## Install on Android
1. Publish the contents of this folder to a static HTTPS host (for example GitHub Pages).
2. Open the hosted URL in Chrome on Android.
3. Choose **Install app** or **Add to Home screen** from Chrome's menu.
4. Open the installed app. It caches the app shell for offline use.

## Data
- No account or database server.
- Workouts and weigh-ins stay in local browser storage.
- Use **Backup** regularly to download a JSON file.
- Restore a JSON backup from **Backup & settings**.
- CSV export is available for workout history.
- Clearing browser site data can erase your records. A backup is essential.
- Local data does not automatically sync to another device.

## Training schedule
The calendar covers November 24, 2026 through June 13, 2027. Monday and Sunday are rest days except race Sundays. April race date can be entered in Settings. Generated sessions are a planning framework; adjust for recovery, pain, illness, weather, and actual event details.
